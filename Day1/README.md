# Day 1 – App Usage / Retention Analysis

## Objective

Develop an app-usage analysis system to understand user engagement and predict user retention.

## Work Completed

* Created a sample app-usage dataset.
* Defined important user engagement features:

  * Login days
  * Session duration
  * Features used
  * Notifications opened
* Split the dataset into training and testing data.
* Trained a Random Forest classification model.
* Evaluated the model using accuracy.
* Tested the model with new user activity data.
* Generated a retention prediction for the user.

## Result

The machine learning model successfully analyzes user activity patterns and predicts whether a user is likely to be retained or may be at risk of churn.

## Technology Used

* Python
* Pandas
* Scikit-learn
* Random Forest
* Google Colab
